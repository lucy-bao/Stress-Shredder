# 撕了算了

使用原生 HTML、CSS、JavaScript 的手机和电脑端自由撕纸工具。页面采用 `dist/index.html` 单文件版本，来自用户提供的 `free-tear-paper (3).html`。

## 本地运行

需要 Node.js 18 或更新版本：

```sh
npm run dev
```

访问 http://localhost:5173 。手机和电脑连接同一 Wi-Fi 后，可通过 `http://电脑局域网IP:5173` 访问。服务绑定所有网卡，勿直接暴露于公网。也可以直接打开 `dist/index.html`。

## 使用

- 在输入框写一句话，点击“换张新纸”更新纸面；支持最多 32 字。
- 在纸上滑动撕开，碎纸片可以继续撕。很小的碎片划过后会消失；纸屑短暂飞溅后自动淡出。
- 上传 JPG、PNG、WebP 等常见图片，图片仅在浏览器本地处理。可随时移除图片。
- “收拾桌面”重新放上一张完整纸；音效可单独开关。
- `npm run check` 检查服务端与页面内联 JavaScript 的语法。

文字与图片不会上传，也不会持久保存。刷新页面会重置当前纸张。
